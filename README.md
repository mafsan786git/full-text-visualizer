# Full Screen Text

A simple browser tool for showing custom text full-screen as a clean YouTube video background.

## Use it

Open `index.html` in your browser, type your text, adjust the style, and press the full-screen button.

Your settings are saved in the browser, so the next time you open the page it keeps your last setup.

## Features

- Live full-screen text preview
- Text, background, font, size, weight, and style controls
- Practical animation presets with speed controls
- Top, center, and bottom positioning
- Auto-fit option for longer text
- Uppercase toggle
- No build step required
